What the game is
----------------
A 2D top-down zombie survival game written with Java Swing (javax.swing, java.awt,
javax.sound.sampled, javax.imageio only). Walk with W A S D, aim with the mouse, kill the
horde, pick up the loot it drops and craft new weapons and upgrades in the workshop (B).
Survive 5 minutes to win.

How to run
----------
Main class: Project3_6813107.MainApplication (Java 26).
NetBeans: open the project folder and press Run.
Command line, from the folder that contains src/:
  javac -d target/classes src/main/java/Project3_6813107/*.java
  java -cp target/classes:src/main/java Project3_6813107.MainApplication
(On Windows use ; instead of : in the class path.)
Pictures and sounds are read from Project3_6813107/resources, either from the class path or
from src/main/java/Project3_6813107/resources relative to the working folder.

Source files (package Project3_6813107)
---------------------------------------
MainApplication.java  launcher window (name, class, options, start weapon, map, high scores)
GameFrame.java        game window: HUD around the GamePanel
GamePanel.java        game loop thread, wave spawner thread, input, camera, drawing
UpgradeDialog.java    workshop dialog with the crafting JTable
Theme.java            Hollow Creek UI kit theme: 9-slice panels, buttons, font, slots, cursors
Entity.java           superclass of everything in the world (position, hitbox, hp, collision)
Player.java           the survivor: movement, weapons, inventory, crafting, upgrades
Monster.java          the 5 enemies (zombie, runner, toxic zombie, bandit, boss)
Bullet.java           bullets, rockets, grenades, enemy shots and melee swings
DroppedItem.java      loot on the ground (magnet pickup, supply chests)
GameMap.java          the 5 arenas: ground, props, walls, collision, spawn points, path finding
GameData.java         all game data: enums for items, weapons, monsters, classes, maps, recipes
AssetLoader.java      loads and cuts sprite sheets, plays sounds (never crashes on missing files)

Resources

resources/weapons     weapon sheet, shoot and glint strips, projectiles
resources/items       loot animation strips (16x16 frames), supply chest (32x16 frames)
resources/tiles       wasteland / interior / camp tile sheets, flame barrel and flag strips
resources/ui/kit      Hollow Creek UI Kit sprites, 9-slice panels, buttons, cursors, pixel font
resources/ui          explosion, impact, alert and particle effects
resources/sounds      original sound effects and looping music made for this project (.wav)
