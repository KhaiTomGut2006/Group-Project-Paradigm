HOLLOW CREEK - UI KIT (FREE)
Pixel art UI for zombie / survival / horror games

panels/        metal, paper note, danger stripe and glass panels (48x48) + 9-slice parts, dialog box
buttons/       blank buttons (32 / 48 px) in 4 states, labeled buttons (START, OPTIONS, QUIT, CONTINUE, BACK),
               checkbox, slider
bars/          health, stamina, infection, water, ammo bars (frame + fill + 5 preset levels),
               segmented health bar, hearts (full / half / empty)
status_icons/  bleeding, infected, hungry, thirsty, tired, cold, injured, noise, hidden, armored, poisoned
cursors/       4 crosshairs, arrow / hand / attack cursors
keys/          keyboard keys W A S D E F R Q 1-5 (+ pressed), ESC, TAB, SHIFT, CTRL, SPACE, ENTER, mouse buttons
hud/           portraits, minimap frames (square / round), map markers, inventory slots, hotbar,
               ammo counter, day banner
titles/        YOU DIED, PAUSED, GAME OVER, SURVIVED, WAVE
font/          3x5 pixel font sheet + font_map.json (glyph order and widths)

Tip: scale the UI by whole numbers (2x, 3x) with nearest-neighbour filtering.
